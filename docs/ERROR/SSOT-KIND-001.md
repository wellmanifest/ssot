# SSOT-KIND-001

## Meaning

The document uses an unknown schema, kind, relationship, action, or packaging
value.

## Cause

A typo, a competing vocabulary, or a document that is not an SSOT interview
or decision.

## Resolution

Use only the kinds declared in `schemas/ssot-decision.schema.json`. Do not
invent a parallel language; this pack sits on `wellmanifest/dsl`.
